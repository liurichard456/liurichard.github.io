Hello World：我的博客正式开张啦

📅 2026-10-31 🏷️ 随笔 ✍️ lgy宇

你好，欢迎来到我的博客！这是我的第一篇文章，按照程序员的传统，第一篇文章当然要说一句：Hello, World!

为什么要写博客

我是一名来自湖北武汉的本科生，今年 20 岁。平时喜欢听歌、记录生活，一直想有一个属于自己的小角落，把学到的东西、听到的歌、遇到的事都记下来。于是就有了这个博客。

写博客对我来说有几个意义：

  • 记录成长：把学习和生活中的收获写下来，回头看看自己走了多远。
  • 整理思路：写下来的过程，也是把知识想清楚的过程。
  • 分享交流：也许某一天，我写的内容能帮到和我有同样困惑的人。

这个博客是怎么搭起来的

这个博客用纯 HTML + CSS 手写，部署在 GitHub Pages 上。没有用复杂的框架，就是想让一切尽量简单。之后我会慢慢完善它，加入更多文章和功能。

接下来会写些什么

  • 学习随笔：专业课笔记、踩坑记录
  • 音乐分享：我最近常听的歌
  • 生活日常：在武汉读书的日子

希望这个小站能一直更新下去。如果你有任何想法，欢迎发邮件给我：1872453288@qq.com。

那么，就从这里开始吧！
